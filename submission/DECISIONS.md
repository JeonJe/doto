# 도토의 범위와 협업 기록

사용자와 AI가 함께 만든 프로토타입입니다. 아래는 대화에 나온 결정의 요약이며 원문 전체나 사용자의 직접 작성 문서는 아닙니다.

- 처음에는 기존 Claude/Codex 계정으로 대화하는 펫을 구상했으나, 사용자가 AI 기능 제외에 동의해 업데이트 모니터링에 집중했습니다.
- 사용자는 한 화면에 하나의 목적, 도구별 확인 주기, 여러 항목 선택, 필터와 이름순 탐색을 요청했습니다.
- 프리셋은 Claude Code, Codex, Gemini, Grok 네 가지로 좁혔어요. 일반 macOS 앱인 Orca 자동 탐색은 아직 구현하지 않았습니다.
- 가을 다람쥐 컨셉을 선택해 이름과 화면을 도토로 정리했습니다. 기존 데이터 호환용 내부 이름은 Momo를 유지했어요.
- 사용자가 가짜 최소화 화면, 긴 설명, 중복 버튼과 혼용된 상태 문구를 지적해 제거하고 맥 기본 창 동작을 적용했습니다.
- AI가 처음 제공한 npm 링크로는 변경 내용을 알 수 없다는 지적에 따라 Codex의 실제 버전별 릴리스 노트를 연결했습니다. 공식 요약이 없는 경우에는 내용을 만들어내지 않습니다.
- AI 검증은 처음에 단일 설치 경로만 다뤘습니다. 사용자가 터미널에서 Claude가 다시 업데이트되는 문제를 보고해 중복 설치 경로 불일치를 확인했고, 위치 선택과 동일 위치 검증을 추가했어요.
- 모의 도구 테스트 통과를 다른 맥의 실제 설치 성공으로 취급하지 않습니다. 실제 수신 환경과 공증 상태는 별도 배포 판정으로 남깁니다.
