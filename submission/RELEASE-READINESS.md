## 일반 공개 배포를 막는 조건

1. **Developer ID Application 서명과 Apple 공증 미완료.** 로컬에 Apple Development 인증서 1개만 확인됐으며 Developer ID Application 인증서는 없음. 최신 산출물도 Gatekeeper 평가 rejected.
2. **실제 다른 Mac 최초 실행 미검증.** 같은 맥의 격리 검사나 Docker 검사는 다른 맥의 Finder 최초 실행과 절전 복귀를 대신하지 않음.

만든 결과물의 시연/공모전 자료는 준비할 수 있지만, 누구나 다운로드해 바로 쓸 수 있는 일반 배포로 안내하지 않습니다.

## 검증 경계

- 실제 사용자 패키지를 이번 점검으로 업데이트하거나 삭제하지 않았음. 업데이트 동작은 격리된 가짜 CLI/npm/Homebrew에서 검사.
- 실제 사용자 환경에서는 중복 설치 경로와 각 버전, 선택 전 차단 화면을 확인.
- 모든 macOS 앱, PATH 밖의 도구, 별도 Homebrew tap, 로그인 자동 실행과 자동 업데이트는 미지원.
- Apple Silicon 빌드, macOS 13 이상 대상. 최소 버전 실기와 Intel은 미검증.
- 진단 기록과 사용자 상태는 전달 파일에서 제외. 소스 공개 시에도 전체 작업 폴더 대신 검증한 전달 범위만 사용.
