도토 0.1.0 심사용 개발 빌드

내가 고른 개발 도구에 새 버전이 나오면 알려주는 맥 앱입니다. AI 계정 연결은 필요 없습니다.

설치
1. Doto.app을 Applications 폴더로 복사합니다. 앱에는 도토로 표시됩니다.
2. 앱을 열고 미리 준비된 도구를 선택하거나 ‘다른 도구 찾기’를 누릅니다.
3. 확인 주기를 정해 추가합니다. 설치 위치가 여러 개면 상세에서 사용할 위치를 선택하세요.

사용
- 새 버전이 있으면 알림을 표시합니다. 업데이트할 항목을 여러 개 선택할 수 있습니다.
- 설치 위치가 여러 개면 선택한 위치만 업데이트하고 결과 버전을 확인합니다.
- 창을 닫아도 실행은 계속됩니다. 메뉴 막대에서 다시 열고 Cmd+Q로 종료하세요.
- 앱이 종료되거나 맥이 잠들면 확인하지 않습니다.
- 자동 업데이트와 로그인 시 자동 실행은 제공하지 않습니다.

지원 범위
Apple Silicon, macOS 13 이상을 대상으로 빌드했습니다. Node.js는 포함되어 있고 버전 조회에는 인터넷이 필요합니다. Homebrew 공식 core/cask, npm 전역 패키지, 알려진 CLI와 공개 GitHub 릴리스를 지원합니다. 모든 macOS 앱이나 PATH 밖의 설치를 찾지는 않습니다. 터미널의 실행 경로와 다를 수 있으니 상세의 설치 위치를 확인하세요.

배포 상태
개발자 인증서 서명과 Apple 공증이 없는 개발 빌드입니다. 다른 맥의 최초 실행은 아직 검증하지 못했고 macOS가 실행을 차단할 수 있습니다. 보안 설정을 자동 변경하는 도구는 포함하지 않았습니다.
Apple 안내: https://support.apple.com/guide/mac-help/mh40616/mac

수동 업데이트에는 설치 관리자와 권한이 필요합니다. 모의 도구로 경로와 실패 처리를 검증했으며 모든 실제 패키지 설치 성공을 보장하지 않습니다.

데이터와 제거
데이터는 ~/Library/Application Support/MomoPrototype에 저장합니다. 설치 파일에는 제작자의 모니터링이나 계정 정보를 포함하지 않습니다. 앱을 종료한 뒤 Doto.app을 휴지통으로 옮기면 제거됩니다. 모니터링 데이터는 재설치를 위해 남습니다.

받는 맥에서 확인
SECOND-MAC-CHECK.md에 최초 실행, 추가, 경로 선택, 알림, 종료/재실행과 잠자기 복귀 결과를 적어주세요.
선택 검사: bash verify-mac.sh /Applications/Doto.app
이 명령은 번들 런타임의 빈 환경 실행을 확인하며 Finder 최초 실행과 화면 검증을 대체하지 않습니다.
